## Sınav için kavram düzeltmeleri

| Yanlış genelleme                | Doğru kapsam                                           |
| ------------------------------- | ------------------------------------------------------ |
| VPN tüm yolu korur              | Cihaz–VPN ucu; sonrası için HTTPS gerekir              |
| DNS şifrelemesi her şeyi gizler | Sorguyu resolver’a kadar gizler; IP/metadata kalabilir |
| DNSSEC gizlilik sağlar          | İmza doğrulaması/bütünlük sağlar, şifrelemez           |
| NAT güvenlik duvarıdır          | Adres çevirisidir; tam erişim politikası değildir      |
| Firewall iç saldırıyı durdurur  | Segmentasyon yanal hareketi sınırlar                   |
| Switch’te trafik görünmez       | ARP/MAC saldırıları ve yapılandırma riskleri sürer     |
| Şifreleme DoS’u önler           | Gizlilik/bütünlük; erişilebilirlik başka kontroldür    |
| IDS trafiği keser               | IDS alarm; IPS inline engelleme yapabilir              |

Kontrolü CIA hedefi, kapsamı, uç noktası ve varsayımlarıyla açıklayın.
