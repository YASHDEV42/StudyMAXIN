- **Loadable Kernel Module (LKM):** Boot'ta veya çalışma sırasında kernel'e eklenir; sürücü/dosya sistemi örnekleri.
- **Linux:** Monolithic kernel + modular destek. **Modül ≠ user-space microkernel servisi**.
- **Hybrid:** Birkaç mimari yaklaşımı birleştirir; performans/güvenlik/bakım dengesi.
- **Mac OS X (kaynak modeli):** Aqua → Cocoa/services → Mach + BSD + I/O Kit/kernel extensions.
- **Mach:** IPC, thread ve bellek mekanizmaları. **BSD:** UNIX, dosya ve ağ hizmetleri.
- **iOS:** Core OS → Core Services → Media Services → Cocoa Touch.
- **Android (eski slayt):** Linux kernel → Libraries/Android Runtime (Dalvik) → Application Framework → Applications.
- **Android Linux kernel görevleri:** Bellek/process, aygıt sürücüleri, power management.

**Sınav notu:** Mac OS X ve Dalvik örnekleri tarihsel slayt yapılarıdır; her güncel sürümü birebir temsil etmez.
