- **System call:** Kernel hizmetine kontrollü arayüz.
- **System program / utility:** Kernel hizmetlerini kullanan araç; kernel'in parçası olmak zorunda değil.
- **File management:** Create/delete/copy/rename/print/list.
- **Status information:** Time, free memory/disk, user count, performance, logs, registry.
- **File modification:** Editör ve içerik dönüştürme.
- **Language support:** Compiler, assembler, debugger, interpreter.
- **Loading/execution:** Executable'ı belleğe yükle, çalıştır.
- **Communications:** E-posta, web, mesaj, uzak bağlantı, dosya aktarımı.
- **Daemon / background service:** Açılışta başlayıp uzun süre çalışan hizmet; ağ, yazdırma ve hata izleme.

**Sınav farkı:** `cp` bir utility'dir; `read` / `write` kernel hizmetlerine erişen çağrılardır. Application program ≠ kernel.
