- **Debugging:** Bug/hata nedenlerini bulma ve giderme.
- **Log:** Olay ve hata bilgilerini kaydetme.
- **Memory dump / core dump:** Hata anı bellek/yürütme durumunun kaydı; debugger inceler.
- **Kernel crash:** Çekirdekte ciddi hata; sistemi etkileyebilir.
- **Performance tuning:** Sistem performansını iyileştirme.
- **Monitoring:** CPU, RAM, I/O, network kullanımını izleme.
- **Bottleneck:** Sistem hızını sınırlayan kaynak.
- **Task Manager:** Windows kaynak ve process izleme aracı.

**Fark:** Debugging = neden yanlış/çöktü? Tuning = neden yavaş/verimsiz?

**Ödev:** Kernel debugging hakkında araştırma (64 sayfalık kaynağın son sayfası).
