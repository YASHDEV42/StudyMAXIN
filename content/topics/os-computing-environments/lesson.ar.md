## Computing Environments (hesaplama ortamları)
حسب المحاضرة، نظام التشغيل ما عنده تصميم واحد لكل الأجهزة. بالـ **Traditional Computing (geleneksel hesaplama)** في أجهزة شخصية وسيرفرات، بينما الـ **Mobile Computing (mobil hesaplama)** بيعطي وزنًا أكبر للبطارية، الاتصال اللاسلكي، والواجهة التفاعلية.

بالـ **Client–Server (istemci-sunucu)** العميل بيبعت طلب، والسيرفر بيقدّم خدمة مثل ملف أو صفحة أو نتيجة حساب. بالـ **Peer-to-Peer / P2P (eşler arası)** الأجهزة بتقدر تشتغل كطالبة ومقدمة للخدمة، بدل الاعتماد دائمًا على Server مركزي.

## Cloud Computing (bulut bilişim)
الـ Cloud بيوفر موارد حوسبة وتخزين وتطبيقات عبر الشبكة. الشرائح بتفرّق بين:
- **Public Cloud (genel bulut):** موارد معروضة للزبائن عبر مزود خدمة.
- **Private Cloud (özel bulut):** بيئة مخصصة لمؤسسة.
- **Hybrid Cloud (hibrit bulut):** دمج عناصر عامة وخاصة.

وبتفصّل نماذج الخدمات:
- **SaaS — Software as a Service (hizmet olarak yazılım):** استخدام تطبيق جاهز عبر الشبكة.
- **PaaS — Platform as a Service (hizmet olarak platform):** بيئة أو منصة لتطوير وتشغيل التطبيقات.
- **IaaS — Infrastructure as a Service (hizmet olarak altyapı):** موارد بنية تحتية مثل السيرفرات والتخزين.

بيئات السحابة بتستخدم أنظمة تشغيل وVMM وأدوات إدارة، ومعها وسائل حماية مثل Firewall (güvenlik duvarı) وتوزيع الحمل **Load Balancing (yük dengeleme)**.

## Real-Time Embedded Systems (gerçek zamanlı gömülü sistemler)
الـ **Embedded System (gömülü sistem)** كمبيوتر مخصص داخل جهاز، مثل وحدة تحكّم صناعية أو نظام سيارات. بالـ **Real-Time System (gerçek zamanlı sistem)** ما بكفي الجواب يكون صحيح منطقيًا: لازم يوصل ضمن **Deadline (son teslim süresi / zaman sınırı)** محدد. مو كل Embedded System بالضرورة بيشغّل OS كامل؛ بعض الأجهزة بتنّفذ مهامها بعتاد أو Firmware متخصص.

## Free and Open Source
بتعرض المحاضرة الفرق بين **Free Software (özgür yazılım)**، اللي كلمة Free فيه بتشير لحرية الاستخدام والتعديل وإعادة التوزيع ضمن الترخيص، وبين **Open Source (açık kaynak)** اللي بيركّز على إتاحة الكود وشروط الترخيص. مشاريع مثل **GNU (GNU projesi)** والـ **Linux Kernel (Linux çekirdeği)** اجتمعت بنظم GNU/Linux. من الأمثلة على التوزيعات Debian وFedora وUbuntu. وتذكر الشرائح دور FSF وGPL.
